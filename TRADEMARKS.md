## Official download sources

Only these are official:

- **GitHub Releases** of this repository:
  <https://github.com/sarmadiq9090-coder/Remember-Me/releases>
  (`Remember-Me-Setup-<version>-x64.exe`, with `SHA256SUMS.txt` and build provenance; see
  [Verify the download](README.md#verify-the-download)). The app's built-in updater downloads
  only from here.
- **Website**: <https://fastkiwi.app/Remember-Me/>
- **Microsoft Store**: **Remember Me Reminders** (Store ID `9NGB1F7T7JGN`), once it is listed.
- **winget**: `Sarmad.RememberMe`, once it is accepted into
  [microsoft/winget-pkgs](https://github.com/microsoft/winget-pkgs).
- **Chocolatey**: `remember-me`, once it is published on the Chocolatey Community Repository.
- **Scoop**: `remember-me`, once its bucket is published and linked from the README.

A copy from anywhere else is not official, even if it uses the Remember Me name or icon.

## Reporting impersonation

If you find a copy that uses the Remember Me or FastKiwi name or icon and pretends to be official,
please tell us:

- open an issue: <https://github.com/sarmadiq9090-coder/Remember-Me/issues/new>, or
- use the support page: <https://fastkiwi.app/support/>.

Include the link and, if you can, a screenshot. If the copy contains malware, also report it
privately as described in [SECURITY.md](SECURITY.md).
