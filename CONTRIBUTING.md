# المساهمة | Contributing

شكرًا لرغبتك في تحسين ذكرني. افتح Issue قبل التغييرات الكبيرة، واجعل كل Pull Request يركّز على مشكلة واحدة.

Thank you for improving Remember Me. Open an issue before large changes and keep each pull request focused on one problem.

## Development

1. Install Node.js 22 or newer.
2. Run `npm install`.
3. Start the app with `npm start`.
4. Run `npm test` before submitting.

Keep Arabic and English interface text in sync. Do not commit user data, attachments, backups, installers, or generated release folders.
