# Contributing

Thank you for improving Remember Me. Open an issue before large changes, and keep each pull request focused on one problem.

## Development

1. Install Node.js 22 or newer and pnpm 10.
2. Run `pnpm install`.
3. Start the app with `pnpm start`.
4. Run `pnpm test` before submitting.

Keep every interface language in sync when you add or change text. Do not commit user data, attachments, backups, installers, or generated release folders.
