A security update. Translated text can no longer add markup to the app, and windows cannot open other pages. Your tasks, notes, attachments and settings load unchanged.

## Highlights

- **Translations are always shown as text.** They are escaped wherever the pages build markup, so a bad translation can no longer add markup or scripts to the app. [#98]
- **Every window blocks new windows, navigation and webviews,** including any window added later, and links open in your browser only when they are `https://` addresses. [#98]

## Installing

If you use v1.5.0 or later and allowed automatic updates, Remember Me updates itself: choose **Restart now** when the banner appears, or it installs the next time you quit. Otherwise, download `Remember-Me-Setup-1.6.2-x64.exe` below and install it over your current version. Your tasks, notes and settings stay as they are.

The installer is not code-signed yet, so Windows SmartScreen may show "Windows protected your PC". Check the download first, then choose **More info → Run anyway**:

```powershell
Get-FileHash .\Remember-Me-Setup-1.6.2-x64.exe -Algorithm SHA256   # compare with SHA256SUMS.txt
gh attestation verify .\Remember-Me-Setup-1.6.2-x64.exe --repo sarmadiq9090-coder/Remember-Me --source-ref refs/tags/v1.6.2 --signer-workflow sarmadiq9090-coder/Remember-Me/.github/workflows/release.yml
```

## Everything in this release

### Fixed

- A snooze time out of range in Settings now says "Choose a time from 01:00 to 23:59." instead of asking for a number. [#94]

### Security

- Translated text is always shown as text: it is escaped wherever the pages build markup, a test fails if a translation contains `<` or `>`, and ESLint rejects unescaped translations in markup. A bad translation can no longer add markup or scripts to the app. [#98]
- Every window, including any added later, blocks new windows, navigation and webviews, and links open in the browser only when they are `https://` addresses. [#98]

### For contributors

- The installer build exits with an error when electron-builder fails, so a broken build can't look green. [#95]
