A small release with fixes for the v1.6.0 snooze choices and overdue wording, and clearer Hindi. Your tasks, notes, attachments, settings and snooze choices load unchanged.

## Highlights

- **Snooze choices for today show their time,** such as "Today 9:00 PM", and Settings refuses a time today before 01:00, which could never be used. [#67]
- **Overdue wording** rounds to the next unit ("1 hour", not "60 minutes"), and the Arabic text on task rows is grammatical for every length. [#67]
- **Clearer Hindi** in 27 strings, thanks to @abhi478jeetur-rgb. [#70]

## Installing

If you use v1.5.0 or v1.6.0 and allowed automatic updates, Remember Me updates itself: choose **Restart now** when the banner appears, or it installs the next time you quit. Otherwise, download `Remember-Me-Setup-1.6.1-x64.exe` below and install it over your current version. Your tasks, notes and settings stay as they are.

The installer is not code-signed yet, so Windows SmartScreen may show "Windows protected your PC". Check the download first, then choose **More info → Run anyway**:

```powershell
Get-FileHash .\Remember-Me-Setup-1.6.1-x64.exe -Algorithm SHA256   # compare with SHA256SUMS.txt
gh attestation verify .\Remember-Me-Setup-1.6.1-x64.exe --repo sarmadiq9090-coder/Remember-Me --source-ref refs/tags/v1.6.1 --signer-workflow sarmadiq9090-coder/Remember-Me/.github/workflows/release.yml
```

## Everything in this release

### Fixed

- A snooze choice for a time today before 01:00 could never be used, because it closes an hour before its time. Settings now asks for 01:00 or later. [#67]
- Snooze choices for today show their time, such as "Today 9:00 PM", so two evening choices no longer share the label "This evening". The default 18:00 choice keeps it. [#67]
- Overdue times round to the next unit: 59 and a half minutes reads "1 hour", not "60 minutes", in the alert and on task rows. [#67]
- Changing the snooze choices while the alert's Pick a time form is open no longer closes it and clears the typed time. [#67]
- Arabic: the overdue text on task rows is grammatical for every length ("مضى على موعدها ساعتان"). [#67]

### Changed

- Hindi: clearer, more natural wording in 27 strings, such as "रोज़ाना" for Daily and "लोकल" instead of "स्थानीय". Thanks to @abhi478jeetur-rgb. [#70]
- Electron 45.1.0. [#72]

### For contributors

- The distribution tests read the release version from `package.json`, and the Scoop and Chocolatey files point at v1.6.0. [#66]
- The README and website describe the v1.6.0 features, and the README has a roadmap. [#68] [#91]
- actions/checkout updated to 7.0.1. [#71]

### Upgrading

- v1.5.0 and v1.6.0 update themselves if you allowed automatic updates. Otherwise, install v1.6.1 over them; your data stays where it is.

See the [code signing policy](https://github.com/sarmadiq9090-coder/Remember-Me#code-signing-policy).
