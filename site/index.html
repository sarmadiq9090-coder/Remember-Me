Everything a busy day needs, nothing it doesn't

Tasks, notes and reminders in one calm window. It runs quietly next to the clock and starts with Windows if you like.

Reminders that stay

A sticky window above the taskbar shows how overdue a task is, its priority and repeat. Reminders that come due together are queued, one at a time, so none is lost.

Snooze that thinks ahead

10 minutes, 1 hour, this evening, tomorrow at 9:00, next week, or any time you pick, on the 1–6 keys. Set your own six choices, see where each one leads before you press it, and use Snooze all when several are waiting.

Repeats that make sense

Daily, chosen weekdays, every few days, monthly or yearly, at the same time even across daylight saving. Skip this time or move only this time.

Tags and checklists

Tag tasks and filter by tag, sort by due time, priority or title, and break a task into steps you tick off right in the list.

Notes your way

Sticky notes, lined paper or plain cards in ten paper colors, with search that finds Arabic text whatever the diacritics or spelling variant.

12 languages

English, Arabic with a full right-to-left layout, and ten more. Dates and numbers follow your language, always with digits 0-9.

Comfortable to use

Light, dark or follow Windows, six color palettes including high contrast, full keyboard use and screen-reader support.

Backups you control

Full backups with checksums, verified before they're restored. Copy them every day into a Google Drive folder if you want an off-site copy.

Files and images

Attach PDFs, sheets, documents and photos to tasks and notes. Programs and scripts are shown in File Explorer instead of being run.

Why not just Windows notifications?

A Windows notification slides in, waits a few seconds and is gone. If you were away or busy, it sits in the notification center until you happen to look.

  • It stays until you answer. The reminder window keeps its place above the taskbar, on top of other windows, until you choose Done or a snooze.
  • Nothing gets buried. When several reminders come due, they wait in a queue with a 1 of N counter.
  • Missed is not lost. Reminders that came due while the PC was asleep appear as soon as you're back.
  • Quiet when you want it. Pause reminders for an hour, until tomorrow or until you resume, right from the notification area.
  • Optional early notice. Get a normal Windows notification from 5 minutes to a day before, and the sticky reminder on time.

Your tasks stay on your PC

Remember Me works offline and has no account, analytics or telemetry. There is no server that could see your tasks.

Stored locally

Tasks, notes, attachments and settings live in %APPDATA%\Remember Me, saved safely with a backup copy and automatic recovery.

Only what you ask for

The app goes online only to check GitHub for updates, if you allow it. None of your data is sent. Backups go only to folders you choose.

Open to inspect

The full source is on GitHub under the MIT license, and every installer is built there from that source, with a checksum and build provenance.

Install in a minute

  1. Download Remember-Me-Setup-1.6.0-x64.exe from the latest release.
  2. Run it. If Windows shows "Windows protected your PC", choose More info, then Run anyway. Why?
  3. Add your first task. Turn on Start with Windows in Settings so reminders are always on time.

Why does SmartScreen warn about it?

The installer isn't code-signed yet, and Windows SmartScreen warns about new unsigned programs that few people have downloaded. It doesn't mean anything was found in the file. You can check that your download is exactly what GitHub built from the public source:

1. Compare the SHA-256 checksum with SHA256SUMS.txt from the same release:

Get-FileHash .\Remember-Me-Setup-1.6.0-x64.exe -Algorithm SHA256

2. Or verify the build provenance with the GitHub CLI:

gh attestation verify .\Remember-Me-Setup-1.6.0-x64.exe --repo sarmadiq9090-coder/Remember-Me

See the code signing policy.

Questions

Is it really free?

Yes. Remember Me is open source under the MIT license, with no ads, no paid tier and no account.

Does it need the internet?

No. Everything works offline. If you allow automatic updates, it checks GitHub for new versions about once a day.

Can I use it on my phone or another PC?

It's a Windows app and doesn't sync. You can export a backup, or copy backups into a Google Drive folder, and restore it on another PC.

Will I get reminders when the app is closed?

Closing the window keeps Remember Me running next to the clock, so reminders still appear. Turn on Start with Windows so it's running after a restart. Reminders missed while the PC was off or asleep appear as soon as you're back.

How do updates work?

The app asks once whether it may update itself. If you agree, it downloads new versions from GitHub in the background, saves a safety copy of your data, and installs when you restart it. Nothing restarts without you.

Which Windows versions are supported?

Windows 10 and 11, 64-bit.

How do I uninstall it?

From Settings → Apps in Windows. Your data folder is kept, in case you want it back.

Can I help translate it or report a problem?

Yes, please. Ten of the languages are machine-assisted and native speakers' corrections are very welcome. See how to fix a translation or open an issue.
